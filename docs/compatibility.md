# 兼容性与验证状态

更新日期：2026-11-09。下面分别记录产品目标和已完成的验证，避免将成功构建当作目标系统已经运行通过。

## 平台

| 平台 | 产品目标 | 当前证据 |
| --- | --- | --- |
| macOS arm64 | macOS 15 起 | macOS 27 arm64 的 CLI、系统凭证、PTY 菜单、MCP、安装升级通过；macOS 15 和 GUI 宿主仍待实测。 |
| macOS amd64 | macOS 15 起，原生 Intel Mac | 已构建并核查归档；原生运行待实测。 |
| Windows amd64 | Windows 10 22H2、Windows 11 | 同一 exe 已构建并核查归档；两个系统各自的真实运行待用户验收。 |
| 其他平台 | 首版未承诺 | Windows ARM64、Linux、32 位系统等尚未纳入正式范围。 |

运行预编译程序无需 Go。源码开发与构建固定 Go 1.27.3。

Git 集成功能基线为 **Git 2.43**。Apple Git 2.50.1 和隔离 Git 2.43.7 core 样本已有验证，后者不包含完整 HTTP／SSH Git 分发能力。Windows Git for Windows／GCM 组合仍待实测。没有 Git 时，可以通过显式实例、仓库和 token 使用远端 API；本地仓库发现、helper 复用及 Git 查询需要 Git。

Windows 目标包含 PowerShell 5.1，Windows 11 另验证 PowerShell 7.6；终端宿主与 shell 分别记录。POSIX PTY 的成功结果不代替 Terminal、iTerm2、Windows Terminal 或传统控制台的实际表现。

## 发布状态与问题反馈

当前项目版本为 **v0.1.0-rc.3**（Windows 一键安装命令修复候选），由 [VERSION](../cmd/sotea/VERSION) 统一管理。版本切换后的构建需独立核验，前述历史候选的验证范围不自动扩大到新产物。

当前处于发布前验收，尚未批准正式稳定版交付。GitHub Release 打包发布及首次安装脚本已实现，实际公开文件以 Releases 为准；剩余条件包括目标平台及终端实测、四客户端完整 UI、新版本公开下载／安装与升级验收及签名／公证策略。候选的摘要与构建来源随包提供。rc.1／rc.2 的三平台托管原生检查、公开 macOS arm64 首次安装及 rc.1→rc.2 升级已通过。rc.3 补充 Windows PowerShell 5.1／PowerShell 实际文档命令的带 BOM／无 BOM 文本执行，以及完整文本安装检查；新产物的公开下载、安装和 rc.2→rc.3 升级仍需独立复核。托管检查不替代桌面系统／GUI 验收。

反馈问题时提供 sotea 版本、操作系统／架构、终端或客户端版本、Gitea 精确版本、脱敏命令和错误码。不要附 token、完整凭证配置或系统密钥。Windows 可使用 [验证指南](windows-validation.md)收集基础结果。
